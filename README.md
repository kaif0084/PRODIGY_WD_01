# PRODIGY_WD_01 — Responsive Navigation Menu

A responsive, single-page creative studio landing page featuring a fixed navigation bar, mobile menu, and scroll-aware active section links.

## Features
- Responsive desktop and mobile navigation with accessible toggle state
- Navigation bar styling changes after scrolling
- Active section link updates while scrolling
- Smooth anchor navigation and reduced-motion support
- Sections for Home, About, Work, Journal, and Contact

## Run locally
Open `index.html` in a modern browser. No build tools, packages, or credentials are required. Google Fonts are loaded from Google Fonts when an internet connection is available; system fonts remain the fallback.

## Files
- `index.html` — page structure
- `styles.css` — layout and responsive styles
- `app.js` — menu, scroll, and active-section behavior
